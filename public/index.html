Sobre

Este projeto foi desenvolvido como parte do Trabalho Prático da disciplina de Desenvolvimento Web Front-End da PUC Minas. O site Psicologia para Todos é uma aplicação dedicada a conectar pessoas com profissionais de psicologia qualificados, promovendo o acesso à saúde mental de forma prática e acessível.
